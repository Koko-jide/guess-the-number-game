# Number Guessing Game

Simple browser-based number guessing game. Open `index.html` in your browser to play.

Changes made in this update:
- Wrapped inputs in a semantic `<form>` so Enter submits correctly.
- Added a "Restart" button and implemented reset logic.
- Show attempts remaining and previous guesses.
- Fixed CSS issues: removed invalid properties, added responsive layout and focus styles.

How to run

Double-click `index.html`, or from PowerShell run:

```powershell
ii .\index.html
```

Notes
- This is a static page — no build or server required. For local testing with live reload, serve the folder with a simple HTTP server.
